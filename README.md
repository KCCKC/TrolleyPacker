# PUDU Delivery Robot Trolley Rack & Placement Optimizer

An AI-powered 3D bin packing and stock placement optimizer designed for PUDU industrial delivery robots (T300, T600, T600 Underride).

---

## 📁 Project Directory Structure

```
C:\Users\User\.gemini\antigravity\scratch\trolley-packer\
├── index.html               # Main Web Application Interface (PUDU Academy Theme)
├── style.css                # CSS Design Tokens & Layout Styles
├── app.js                   # 3D Bin Packing Engine & WebGL Visualizer
├── trolley_cli.py           # Interactive Python Terminal CLI App
├── open_app_window.bat      # Native App Window Mode Launcher
├── create_shortcut.ps1      # Desktop Shortcut Generator Script
└── .antigravity/            # Antigravity Active Workspace Marker
```

---

## 🚀 How to Run

- **Desktop Shortcut**: Double-click `PUDU Trolley Packer.lnk` on your Windows Desktop.
- **Web App**: Open `index.html` directly in any web browser.
- **Terminal CLI**: Run `python trolley_cli.py` in terminal.
